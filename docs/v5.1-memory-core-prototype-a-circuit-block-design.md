# V5.1 — Memory Core Prototype A Circuit-Block Design

## Status

Draft for acceptance.

## Goal

Define the complete functional circuit-block structure for **Memory Core Prototype A** before schematic capture or component selection.

Prototype A must prove the Merrin Grief Synth hardware heart:

```text
MEMORY
GHOST
RETURN
```

with:

```text
ABSENCE
PRESSURE
BREAK
```

The prototype uses an external audio signal as **Present**.

Prototype A remains:

- hybrid analogue/digital
- SMD-first for electronic circuitry
- through-hole only for mechanically appropriate panel/service parts
- Thonkiconn-family 3.5 mm PCB-mount jacks for audio connections
- external-audio driven
- mono in / mono out
- menu-free
- display-free
- oscillator-free

Exact component and footprint choices remain deferred.

## Core circuit decision

The signal captured by Memory is the **shaped Present signal**, after Pressure and Absence.

```text
Raw input
  ↓
Pressure
  ↓
Absence
  ↓
Shaped Present
  ├── direct Present path
  └── Memory-input summing node
```

This means the instrument remembers what the present has already become.

Return enters the Memory-input summing node only after analogue Break shaping and hard safety limiting.

## Signal domains

These are Prototype A design targets. They are not claims about final production format.

| Domain | Target |
|---|---|
| External input, expected | Approximately 0.2 Vpp to 10 Vpp after user trim. |
| External input, survival | No damage from a continuous input within ±12 V at the jack. Normal audio performance is not required at the survival limit. |
| Internal analogue audio nominal | 2 Vpp. |
| Internal analogue audio headroom target | At least 6 Vpp before unintended clipping. Intended Pressure/Break clipping is separate. |
| Converter ingress nominal | Approximately −12 dBFS during ordinary playing. |
| Converter ingress peak target | Remain below −3 dBFS before intentional limiting. |
| Digital control representation | Normalised 0.0 to 1.0 values. |
| Final output nominal | Approximately 2 Vpp at unity-style settings. |
| Final output maximum target | No more than 10 Vpp under any normal control setting. |
| Return small-signal loop target | Approximately 0.85 maximum before nonlinear limiting. |
| Return absolute condition | The complete loop must remain bounded at every knob setting and every valid input condition. |

The final power rails, analogue reference arrangement, converter supply, and control-voltage rail are not selected in V5.1.

## Block definitions

## IN-01 — Thonkiconn audio input

Purpose:

- receive mono external audio
- provide a mechanically robust PCB/panel connection
- optionally use a switched contact for a defined no-cable state

Requirements:

- Thonkiconn connector family
- exact variant deferred
- exact normal contact behaviour documented before schematic approval
- no floating input when no cable is connected
- panel and PCB loads must not be carried only by solder joints where additional support is needed

## IN-02 — Input protection and RF rejection

Purpose:

- prevent common patching mistakes from damaging the signal path
- reduce RF and cable-borne interference before gain stages

Requirements:

- survive the external-input survival target
- limit input current before sensitive devices
- avoid audible loading in the expected input range
- fail toward attenuation or silence rather than uncontrolled output

Exact protection devices and filter values are deferred.

## IN-03 — Input trim and buffer

Purpose:

- accept both lower-level and modular-level source signals
- present a stable impedance to the external source
- create the internal nominal audio level

Requirements:

- manual input trim
- unity-reference mark or repeatable reference position
- enough attenuation to accept the expected maximum input
- enough gain or buffering to make lower-level sources testable
- no deliberate emotional shaping in this block

## PRS-01 — Pressure

Purpose:

Apply controlled gain stress before Memory capture.

Pressure means:

- gain
- saturation
- compression
- constrained dynamic movement

Requirements:

- continuously controllable Pressure amount
- clean or nearly clean behaviour at minimum
- progressive compression/saturation rather than abrupt generic fuzz
- bounded output into Absence
- no unsafe gain jump when adjusted

Pressure must remain distinguishable from Break.

## ABS-01 — Absence

Purpose:

Remove or hollow spectral content before Present is split into direct and remembered paths.

Requirements:

- continuously controllable Absence depth
- must remove content, not merely lower overall level
- fixed safe limits preventing complete unstable gain collapse
- accepts a secondary modulation influence from Return
- Return influence must be bounded and cannot invert the control into an unsafe state

Exact spectral topology is deferred.

## PRES-01 — Direct Present path

Purpose:

Preserve a stable analogue route from shaped Present to the final output mixer.

Requirements:

- does not pass through ADC, digital core, or DAC
- remains available while the digital core boots, resets, or faults
- has a defined gain relationship to the Memory/Ghost wet path
- can be muted only by the final safety/output system
- must not inherit digital fault noise

This path is essential. The instrument must still pass Present when Memory is unavailable.

## SUM-01 — Memory-input summing node

Purpose:

Combine:

1. shaped Present
2. safely limited analogue Return

before ADC conversion.

Requirements:

- shaped Present remains the dominant reference input at normal Return settings
- Return contribution rises smoothly
- no control position permits raw unbounded Return to reach ADC-01
- sufficient headroom for Present plus Return
- overload produces controlled limiting rather than converter abuse

## ADC-01 — Digital ingress boundary

Purpose:

Convert the summed shaped-Present/Return signal into the shared digital core.

Requirements:

- one functional mono ingress path
- analogue anti-alias conditioning
- defined bias/reference removal or handling
- nominal level around −12 dBFS
- peak target below −3 dBFS before intentional limiter action
- converter clipping must not be the normal Break sound

The exact ADC, codec, sample rate, bit depth, and filtering topology are deferred.

## CORE-01 — Shared Memory/Ghost/Return digital core

Purpose:

Use one retained audio history to create three related behaviours.

The core is not three independent effects.

### Memory function

Memory must provide:

- circular retained-audio storage
- Time control
- Fade control
- Blur control
- repeated-circulation degradation
- bandwidth loss or smearing
- soft digital limiting before output conversion

### Ghost function

Ghost must be derived from Memory data.

Ghost must provide:

- Distance control
- Drift control
- Presence control
- thinner spectral content than Memory
- temporal or pitch displacement
- partial obscuration

### Return-send function

Return send must be derived from retained sound and prepared for analogue Break/Return treatment.

Requirements:

- Return amount control is applied before or at the DAC-R boundary
- digital output is bounded
- Return cannot bypass the analogue safety path
- reset can force Return send to zero immediately

## DAC-M — Memory output boundary

Purpose:

Convert Memory into a separately mixable analogue signal.

Requirements:

- dedicated functional output
- post-conversion reconstruction filtering
- known nominal level into MIX-01
- muteable during boot/reset/fault

## DAC-G — Ghost output boundary

Purpose:

Convert Ghost into a separately mixable analogue signal.

Requirements:

- dedicated functional output
- post-conversion reconstruction filtering
- level range allowing Ghost to remain subordinate to Present/Memory
- muteable during boot/reset/fault

## DAC-R — Return-send boundary

Purpose:

Convert the digital Return send into the analogue Break/Return chain.

Requirements:

- dedicated functional output or equivalent isolated converter channel
- post-conversion reconstruction filtering
- zero output during reset/fault
- cannot connect directly to SUM-01 without BRK-01, RET-01, and RET-02

The converter implementation may use one multichannel device or multiple devices. V5.1 locks functional channels, not parts.

## BRK-01 — Break

Purpose:

Create controlled cumulative damage in the returning path.

Break may include, in later schematic form:

- soft clipping
- folding
- compression
- bandwidth loss
- feedback saturation
- controlled instability

Requirements:

- continuously controllable Break amount
- low Break retains intelligibility
- high Break remains bounded
- no direct path to final output that bypasses Return safety
- must sound different from Pressure

## RET-01 — Analogue Return nonlinear stage

Purpose:

Give returned sound a physical analogue alteration before it changes future Memory.

Requirements:

- receives only DAC-R output
- adds nonlinear colour distinct from digital degradation
- remains stable under silence, DC-like content, and sustained tones
- cannot create a full-level transient when Return is raised
- output feeds RET-02, never SUM-01 directly

## RET-02 — Hard Return limiter

Purpose:

Make runaway feedback structurally impossible during normal operation.

Requirements:

- fixed upper limit independent of the Return knob
- limits both positive and negative excursions
- remains active during digital-core faults
- reduces loop gain below the unbounded condition
- operates before both Return recirculation and Absence influence extraction

Design target:

```text
Normal maximum small-signal loop gain ≈ 0.85
Absolute complete-loop behaviour = bounded
```

The exact limiting topology is deferred, but the limiter is mandatory.

## RET-03 — Absence influence extraction

Purpose:

Derive a slow, bounded control influence from limited Return.

Requirements:

- responds to Return activity, not raw external input
- cannot exceed the safe control range of ABS-01
- has enough smoothing to avoid uncontrolled audio-rate zippering unless deliberately accepted later
- zero or neutral influence during reset/fault
- test point available

This block allows past sound to change what the present loses.

## RET-04 — Limited Return feed

Purpose:

Feed altered past sound back into SUM-01.

Requirements:

- only receives RET-02 output
- includes fixed attenuation or gain bounding independent of the front-panel Return control
- has no hidden bypass around the hard limiter
- can be forced to zero by SAFE-01
- test point available before SUM-01

## MIX-01 — Wet mix

Purpose:

Combine Memory and Ghost for the final output path.

Requirements:

- Memory and Ghost remain separately gain-controlled internally or functionally
- Ghost maximum remains subordinate unless a later accepted revision changes this
- summed wet level remains within internal headroom target
- wet path can be muted independently of Present

## MIX-02 — Final mix

Purpose:

Combine:

- direct Present
- Memory/Ghost wet mix

Requirements:

- Present remains audible with wet level at minimum
- wet level can reach an emotionally useful balance without clipping
- no phase/polarity error causes unintended cancellation at ordinary settings
- output level stage follows the mix

Return is heard mainly through its effect on future Memory and Absence, not as an unrelated fourth wet channel.

## OUT-01 — Output level

Purpose:

Provide manual final output control.

Requirements:

- spans silence to the defined maximum output target
- operates after final mix
- has a repeatable reference position
- cannot bypass OUT-02 safety mute/protection

## OUT-02 — Output protection and safe mute

Purpose:

Protect connected equipment and suppress boot/reset/fault transients.

Requirements:

- hardware-capable wet mute independent of normal DSP operation
- known safe state at power-on
- no full-scale click when mute is released
- output protection against reasonable patching faults
- maximum normal output no greater than 10 Vpp
- drives the output Thonkiconn through a stable output stage

## CTRL-01 — Manual control acquisition

Prototype A controls:

### Expressive

- Pressure
- Absence
- Break
- Memory Time
- Memory Fade
- Memory Blur
- Ghost Distance
- Ghost Drift
- Ghost Presence
- Return amount

### Operating

- Input trim
- Present/wet balance
- Output level
- Bypass or safe mute
- Reset/clear memory

Requirements:

- no menu or display
- controls map to normalised 0.0–1.0 values where processed digitally
- analogue controls remain usable without unnecessary digital mediation
- noisy or disconnected control inputs must fail to a bounded value
- exact control voltage and ADC implementation deferred

## SAFE-01 — Boot, reset, mute, and fault controller

Purpose:

Keep the prototype in a known safe state.

Required states:

```text
POWER-OFF
BOOT-MUTED
IDLE-SAFE
ACTIVE
RESET-MUTED
WARNING-LIMIT
ERROR-MUTED
```

Required behaviour:

1. Power-on begins with wet outputs and Return feed muted.
2. Direct Present may become available only after the analogue path is stable.
3. Wet outputs unmute only after CORE-01 reports a valid state.
4. Reset immediately forces Return send and Return feed to zero.
5. Memory is cleared while wet output remains muted.
6. Mute release uses a controlled ramp.
7. Core/watchdog fault forces `ERROR-MUTED`.
8. Direct Present remains recoverable unless the final safety mute is deliberately engaged.

Target response:

- emergency reset/mute command begins suppressing wet/Return paths within 20 ms
- normal unmute occurs only after stable-state confirmation

## LED-01 — SLS-1 state indication

Required states:

| State | Meaning |
|---|---|
| IDLE | Powered, stable, and retaining no significant sound. |
| ACTIVE | Memory/Ghost/Return core is active. |
| WARNING | limiter/Pressure/Return activity is approaching the defined safe boundary. |
| ERROR | core or safety state is invalid; wet/Return paths are muted. |

Requirements:

- SLS-1 patterns, precedence, and sensory limits apply
- colour is not the sole carrier of meaning
- WARNING/ERROR override activity indication
- state LED is not used as an audio meter

## Conversion-boundary requirements

### Analogue to digital

The ADC input receives:

```text
shaped Present + limited Return
```

It must not receive:

- raw untrimmed jack input
- raw DAC-R output
- unbounded Return
- output-mixer signal

### Digital to analogue

Three functional outputs are required:

```text
Memory
Ghost
Return send
```

These may be implemented by a multichannel converter or equivalent architecture later.

The block design does not lock the converter device count.

## Gain-staging plan

| Stage | Normal target | Fault/maximum rule |
|---|---:|---|
| IN-03 output | 2 Vpp | Must remain within analogue headroom. |
| PRS-01 output | 2 Vpp typical | Intentional saturation allowed; bounded before ABS-01. |
| ABS-01 output | 2 Vpp or lower | No gain runaway from Return modulation. |
| SUM-01 output | 2 Vpp nominal | Present + Return must remain within ADC-conditioning headroom. |
| ADC-01 | −12 dBFS nominal | Below −3 dBFS peak target before limiting. |
| DAC-M | 2 Vpp nominal-equivalent | Muted on boot/reset/fault. |
| DAC-G | Below Memory nominal at default | Cannot dominate at default. |
| DAC-R | Bounded converter output | Never reaches SUM-01 directly. |
| RET-02 | Fixed safe ceiling | Complete loop remains bounded. |
| MIX-02 | 2 Vpp nominal | No more than 10 Vpp at final output. |

### Zone B — Quiet analogue input

- IN-02
- IN-03
- PRS-01
- ABS-01
- PRES-01
- SUM-01

### Zone C — Conversion boundary

- ADC ingress conditioning

### Zone D — Digital memory core

### Zone E — Return/high-energy analogue

- BRK-01

### Zone F — Mix/output/safety

- MIX-01

- power entry/protection

## Ground and reference rules

- analogue and digital return currents must be intentionally controlled
- digital clock/current loops must not pass beneath or through quiet input/Absence nodes
- converter reference and analogue reference relationship must be explicit in schematic design
- Thonkiconn sleeve connections must follow the chosen grounding strategy consistently
- panel hardware must not create an undocumented second ground path
- Return/high-gain currents must not share sensitive input traces or reference paths

V5.1 does not prescribe a finished ground-plane layout.

## Bench acceptance procedure

## 1. Documentation check

Confirm:

- every functional block exists
- every interface has a defined direction
- all mandatory test points are present in the later schematic
- no raw Return path bypasses RET-02
- Present has an analogue path around the digital core

## 2. Power-off safety check

Before power:

- verify no hard short between supply domains
- verify output is not directly tied to a supply rail
- verify Return feed cannot bypass its limiter
- verify Thonkiconn switched contacts match the intended no-cable state

## 3. Current-limited power-up

- use a current-limited bench supply appropriate to the later chosen power design
- begin with wet and Return paths muted
- verify no unsafe output transient
- verify IDLE or ERROR state is truthful

## 4. Direct Present path

With digital core disabled or held in reset:

- inject a known sine wave
- verify input trim range
- verify Pressure minimum is near-clean
- verify Absence minimum preserves expected content
- verify Present reaches output
- verify output level spans mute to reference level

Acceptance target:

- unity-reference path within ±1 dB at ordinary settings
- no digital noise on the direct Present path

## 5. Converter loopback

With Memory processing bypassed internally:

- send shaped Present through ADC/core/DAC-M
- verify nominal −12 dBFS operating level
- verify peaks remain below the target limit
- verify reconstruction output is stable
- verify mute suppresses DAC outputs

## 6. Memory test

Verify:

- Time changes retained interval
- Fade changes persistence
- Blur changes retained detail
- repeated circulation produces cumulative degradation
- Memory is not a clean utility delay

## 7. Ghost test

Verify:

- Ghost is derived from Memory
- Distance changes separation
- Drift changes reliability
- Presence changes audibility
- Ghost remains thinner and subordinate at default settings

## 8. Return-path test

Begin with Return at zero.

Increase slowly while monitoring TP-RETSEND, TP-BREAK, TP-RETLIM, TP-SUM, and output.

Verify:

- Break alters returning sound
- analogue Return nonlinearity is audible but bounded
- RET-02 limits before runaway
- Return changes future Memory
- Return influences Absence
- no control position creates uncontrolled escalation

Endurance target:

- 30 minutes at worst valid Return/Break/Pressure settings without runaway, latch-up, or unsafe output

## 9. Reset and fault test

Verify:

- reset begins muting wet/Return paths within 20 ms
- Return feed becomes zero
- memory clears
- controlled unmute occurs only after stable state
- forced core fault produces ERROR and keeps wet/Return muted
- direct Present remains recoverable

## 10. Input and output boundary test

Verify:

- expected 0.2–10 Vpp inputs can be trimmed into the internal nominal range
- survival input does not damage the circuit
- output never exceeds the defined 10 Vpp normal maximum
- output remains controllable at all expressive settings

## 11. Emotional identity test

Within 30 seconds, a user should be able to hear:

- Present
- what remains as Memory
- what detaches as Ghost
- how Return changes what happens next

The result must not present as a normal delay with decorative naming.
