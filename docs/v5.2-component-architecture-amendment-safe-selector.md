# V5.2 — Component Architecture Amendment: Safe VCA-Control Selector

## Status

Authoritative amendment for the V5.2 component architecture and schematic sheet plan.

This document supplements:

- `docs/v5.2-prototype-a-component-architecture.md`
- `docs/v5.2-prototype-a-schematic-sheet-plan.md`

Where those documents refer generically to a hardware attenuation clamp, this amendment defines the selected implementation boundary.

It does not authorise PCB placement, routing, fabrication or purchasing.

## Added major component

| Function | Selected component | Package target | Decision |
|---|---|---|---|
| Four-channel fail-safe VCA-control selector | TMUX1574 | TSSOP-16 | Selected |

## Functional role

TMUX1574 sits between:

```text
MCP4728 normal control outputs
+
+3.3 V safe-attenuation reference
```

and the four SSI2164 control inputs.

For each channel:

```text
SxA = +3.3 V safe attenuation
SxB = MCP4728 normal control
Dx  = SSI2164 control input
```

Control:

```text
SEL low  = select safe attenuation
SEL high = select normal DAC control
EN low   = switch enabled
```

The selector's default low state must select safe attenuation.

## Sheet ownership

The component belongs primarily on:

```text
08_CONTROLS_STATE
```

The hardware fault/release signal originates from the supervisor/watchdog/mute logic and crosses the hierarchy as:

```text
SAFE_CONTROL_RELEASE
```

The four selected outputs cross to the wet/Return VCA circuitry as:

```text
VCA_CTRL_MEMORY_SAFE
VCA_CTRL_GHOST_SAFE
VCA_CTRL_RETURN_SAFE
VCA_CTRL_WET_MASTER_SAFE
```

The generic MCP4728 outputs must not connect directly to SSI2164 control pins.

## Safety boundary

The selector is authoritative while 3.3 V remains valid.

- MCU reset, floating GPIO or explicit fault leaves `SEL` low.
- Hardware fault may pull `SEL` low regardless of MCU output.
- MCP4728 EEPROM/default state cannot bypass the selector.
- Negative SSI2164 control voltage remains forbidden.
- Rail-collapse transient suppression still requires codec mute/reset and the final hardware wet/output mute path.

## Required ERC review

```text
[ ] TMUX1574 supply and logic limits match the 3.3 V domain.
[ ] SxA inputs all receive the safe +3.3 V reference.
[ ] SxB inputs receive only MCP4728 outputs.
[ ] Dx outputs reach only SSI2164 control networks.
[ ] SEL has a defined external safe-state pull-down.
[ ] Hardware fault can force SEL low.
[ ] MCU high cannot override an asserted hardware fault.
[ ] EN cannot leave all controls floating during a normal reset.
[ ] No direct MCP4728-to-SSI2164 bypass exists.
```

## Acceptance meaning

This amendment closes the previously generic phrase:

```text
hardware attenuation clamp
```

at the component-architecture level.

The exact open-drain transistor/logic implementation, decoupling and local protection remain native schematic tasks.
