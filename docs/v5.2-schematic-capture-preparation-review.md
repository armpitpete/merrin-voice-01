# V5.2 — Schematic Capture Preparation Review

## Status

Preparation lane active.

## Purpose

Close the remaining evidence and calculation gaps before native KiCad schematic capture.

This lane does not create unvalidated `.kicad_sch` files.

## Review result

The accepted V5.2 component architecture remains suitable for schematic capture.

The following are confirmed at architecture level:

- STM32H743VI remains an active production MCU family with up to 480 MHz CPU operation and up to 1 MB RAM.
- The selected MCU family provides multiple audio-capable serial interfaces, DMA resources and internal PLLs suitable for the proposed audio-clock role.
- PCM3168A supports TDM and provides six ADC and eight DAC channels.
- PCM3168A supports 48 kHz operation.
- PCM3168A accepts 512 × sample-rate system clock operation for both ADC and DAC sections.
- 24.576 MHz is therefore a valid architecture-level MCLK target at 48 kHz because `24.576 MHz / 48 kHz = 512`.
- TPS3431 provides an active-low open-drain watchdog output and an enable function suitable for the hardware fault-combination plan.

## Accepted clock proof

```text
Sample rate: 48,000 Hz
MCLK target: 24,576,000 Hz
MCLK ratio: 512 × fs
```

PCM3168A documents 512 × fs as a supported system-clock ratio for its ADC and DAC sections at the chosen sample-rate class.

The architecture-level clock target is accepted.

The following still require register-level proof during native schematic/firmware integration:

- exact PCM3168A serial-mode register values
- exact TDM slot format
- exact BCLK edge and data alignment
- exact MCU SAI/TDM configuration
- exact clock-output pin and alternate function

- SWD debug

- reset/clear button
- bypass/safe-mute input

## Rule

```text
No guessed MCU pin may enter the schematic.
```

The pin map is accepted only when:

1. every signal has a named MCU pin;
2. every alternate function is supported on STM32H743VI LQFP-100;
3. no pin conflict exists;
4. boot/debug pins remain usable;
5. analogue control inputs use ADC-capable pins;
6. CubeMX or equivalent official-data verification is stored with the project.

## Remaining closure order

1. STM32 LQFP-100 pin allocation.
2. PCM3168A serial/register proof.
3. 3.3 V and quiet 5 V current/thermal budget.
4. OPA1679 channel count and analogue-current budget.
5. SSI2164 attenuation polarity and hardware-clamp calculation.
6. MCP4728 safe-start verification.
7. TPS3431 timing and fault-combination calculation.
8. WQP518MA symbol, switch contact and footprint verification.
9. Exact protection, clock and power passive selection.
10. Native KiCad hierarchical schematic capture and ERC.

## Stop rule

PCB placement, PCB routing, fabrication outputs and purchasing remain forbidden.
