# Return safety objective

```text
normal maximum small-signal Return loop gain ≤ 0.85
complete Return behaviour bounded at every valid setting
```

The Return knob and VCA are not the hard limiter.

## Locked Return chain

```text
PCM3168A DAC3 Return send
→ DAC-R differential receiver / level scaling
→ BRK-01 Break
→ RET-01 analogue Return nonlinearity
→ 2.2 kΩ series resistor
→ RET-02 dual-polarity hardware clamp
→ RET-02 output buffer
→ RETURN_LIMITED
   ├── fixed RET-04 attenuation → SUM-01
   └── bounded RET-03 Absence influence
```

Only `RETURN_LIMITED` may leave the Return sheet as feedback audio.

# Small-signal gain contract

The earlier fixed-resistor calculation alone was not sufficient because Break and RET-01 also sit inside the loop.

The corrected contract is:

```text
combined small-signal transfer from ADC/core Return source
through DAC-R, BRK-01 and RET-01 to RETURN_LIMITED
must be ≤ 1.000 at every valid control setting
before RET-04 fixed attenuation
```

This means:

- DAC-R scaling establishes the nominal internal level;
- Break may alter shape, clipping threshold and bandwidth;
- RET-01 may add nonlinearity;
- any local gain increase must be followed by compensating attenuation;
- the combined pre-RET-04 small-signal path may not exceed unity.

Break remains emotionally strong through nonlinearity and degradation, not uncontrolled small-signal gain.

The native schematic must include a gain table proving the maximum small-signal transfer is ≤1.000.

# DAC-R scaling

PCM3168A DAC output is differential. The first-pass receiver target is:

```text
gain = 0.25
```

An approximately 8 Vpp differential full-scale signal therefore becomes approximately 2 Vpp single-ended internal audio.

Exact resistor values must preserve codec common-mode isolation and are set during native schematic capture.

# Hard limiter

## References

Create buffered analogue references:

```text
+2.5 V
−2.5 V
```

They are derived from protected ±12 V and remain independent of MCU, codec and control DAC operation.

## Clamp topology

```text
RET-01 output
→ 2.2 kΩ series resistor
→ clamp node
   ├── verified clamp diode to +2.5 V reference
   └── verified clamp diode to −2.5 V reference
→ OPA1679 buffer
→ RETURN_LIMITED
```

BAT54-class Schottky parts are an initial candidate, not an automatic final part. Leakage, forward voltage, capacitance and reference-buffer current must be checked in the native schematic.

Expected first-pass clamp region:

```text
approximately ±2.7 to ±2.8 V
approximately 5.4 to 5.6 Vpp
```

At a hypothetical +10 V RET-01 output and +2.8 V clamp:

```text
I = (10 V − 2.8 V) / 2.2 kΩ
  ≈ 3.27 mA
```

The native schematic must verify both polarities, diode current and reference-buffer source/sink ability.

# Corrected fixed Return-feed attenuation

Locked starting values:

```text
RIN = 40.2 kΩ
RF  = 27.4 kΩ
```

Nominal gain magnitude:

```text
|A| = 27.4 / 40.2
    = 0.6816
```

With 1% resistors, worst high ratio:

```text
Amax = (27.4 × 1.01) / (40.2 × 0.99)
     ≈ 0.6954
```

Locked rounded limits:

```text
nominal fixed feed = 0.682
1% worst-case feed < 0.696
```

The SSI2164 Return channel is restricted to unity maximum and never receives negative control voltage.

With the combined pre-feed small-signal path constrained to unity:

```text
maximum calculated loop gain
≤ 1.000 × 1.000 × 0.6954
≤ 0.696
```

This remains below 0.85 with useful design margin.

# Headroom check

Using the conservative 5.6 Vpp clamp estimate:

```text
maximum returned component
≈ 5.6 Vpp × 0.6816
≈ 3.82 Vpp
```

With 2 Vpp shaped Present:

```text
3.82 Vpp + 2.00 Vpp = 5.82 Vpp
```

This remains below the accepted 6 Vpp internal headroom target before normal ADC conditioning.

Phase relationships can reduce or redistribute the instantaneous sum, but the design does not depend on cancellation.

ADC conditioning must still preserve the −12 dBFS nominal and below −3 dBFS peak targets.

# Absence influence

RET-03 derives control from `RETURN_LIMITED` only:

```text
RETURN_LIMITED
→ precision rectifier
→ attack/release smoothing
→ fixed maximum scaling/clamp
→ ABSENCE_INFLUENCE
```

`ABSENCE_INFLUENCE` must:

- be neutral during reset/fault;
- remain within ABS-01's hardware-safe range;
- avoid an audio-rate positive-feedback path;
- expose a dedicated test point.

# OPA4196 SSI-control buffer allocation

The seven-package, 28-channel OPA1679 audio allocation remains unchanged and fully occupied. SSI2164 control buffering uses one separate OPA4196 quad package:

```text
channel A = Memory control
channel B = Ghost control
channel C = Return control
channel D = wet-master control
```

The OPA4196 is powered from protected +/-12 V, configured as four unity followers, locally bypassed with 100 nF per supply pin and isolated from the SSI2164 control inputs by 20 Ω per channel. Its footprint remains blank pending exact package/land-pattern review.
