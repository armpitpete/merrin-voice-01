# V5.2 — Return Limiter and OPA1679 Allocation

## Status

Draft for acceptance before native schematic capture.

## Purpose

Define the analogue Return safety boundary, fixed loop-gain ceiling, limiter references, and complete OPA1679 channel allocation required by Prototype A.

This document does not authorise PCB placement, routing, fabrication or purchasing.

# Return safety objective

The accepted requirement is:

```text
normal maximum small-signal Return loop gain ≈ 0.85 or lower
complete Return behaviour remains bounded at every valid setting
```

The safety structure must remain effective when:

- Return amount is maximum;
- Break adds gain or strong nonlinearity;
- MCU firmware misbehaves;
- MCP4728 requests unity;
- codec output reaches full scale;
- audio contains sustained or DC-like content.

The Return knob and VCA are not the hard limiter.

# Locked Return chain

```text
PCM3168A DAC3 Return send
        ↓
DAC-R differential receiver / level scaling
        ↓
BRK-01 Break
        ↓
RET-01 analogue Return nonlinearity
        ↓
series limiting resistor
        ↓
RET-02 dual-polarity hardware clamp
        ↓
RET-02 output buffer
        ↓
RETURN_LIMITED
        ├── fixed RET-04 attenuation → SUM-01
        └── RET-03 bounded Absence influence
```

Only `RETURN_LIMITED` may leave the Return sheet as feedback audio.

# DAC-R scaling

PCM3168A DAC outputs are differential and may present approximately 8 Vpp differential at full scale under the selected supply/configuration assumptions.

Prototype A targets approximately 2 Vpp internal nominal-equivalent audio.

Locked differential receiver target:

```text
gain = 0.25
```

Therefore:

```text
8 Vpp differential × 0.25 = approximately 2 Vpp single-ended internal
```

Final resistor values must preserve ratio accuracy and codec common-mode isolation. The exact differential-amplifier values are a native schematic task.

# Break and analogue Return

BRK-01 and RET-01 may create:

- soft clipping;
- compression;
- folding;
- asymmetric damage;
- bandwidth loss;
- controlled gain before limiting.

They may not export directly to SUM-01.

Any gain added by Break/Return is followed by RET-02.

# Hard limiter

## Clamp references

Create buffered analogue references:

```text
+2.5 V
−2.5 V
```

These references are derived from the protected ±12 V analogue rails and remain independent of the MCU, PCM3168A and MCP4728.

Reference buffers must be stable, decoupled and testable.

## Clamp network

Locked starting topology:

```text
RET-01 output
   ↓
2.2 kΩ series resistor
   ↓
clamp node
   ├── low-leakage Schottky diode to +2.5 V reference
   └── low-leakage Schottky diode to −2.5 V reference
   ↓
OPA1679 buffer
   ↓
RETURN_LIMITED
```

Use BAT54-class Schottky devices or a verified equivalent. Exact package and orderable suffix remain schematic-stage decisions.

Because Schottky forward voltage varies with current and temperature, the clamp is specified as a bounded range rather than a false exact value.

Expected first-pass clamp level:

```text
approximately ±2.7 to ±2.8 V
approximately 5.4 to 5.6 Vpp
```

This remains below the accepted 6 Vpp internal analogue headroom target.

## Clamp-current estimate

At a hypothetical +10 V RET-01 output and a +2.8 V clamp node:

```text
I = (10 V − 2.8 V) / 2.2 kΩ
  ≈ 3.27 mA
```

At −10 V the magnitude is similar.

This limits fault/clipping current to a small value while allowing normal low-level audio to pass without diode conduction.

The native schematic must check diode current, reference-buffer sink/source ability and OPA1679 input protection at the selected worst-case RET-01 output.

# Fixed Return-feed attenuation

RET-04 uses a fixed inverting gain magnitude:

```text
RIN = 40.2 kΩ
RF  = 30.1 kΩ
```

Gain magnitude:

```text
|A| = RF / RIN
    = 30.1 / 40.2
    = 0.7488
```

Locked rounded value:

```text
0.749 maximum nominal fixed recirculation gain
```

The SSI2164 Return channel is restricted to:

```text
0 dB maximum / unity
no negative control voltage
no gain above unity
```

Therefore the normal small-signal Return path is bounded by:

```text
0.749 × 1.000 = 0.749
```

This is below the V5.1 target of approximately 0.85.

Even if BRK-01/RET-01 create local gain, RET-02 bounds the amplitude before the fixed recirculation stage.

## Tolerance check

With 1% resistors, worst ratio occurs with RF high and RIN low:

```text
Amax = (30.1 kΩ × 1.01) / (40.2 kΩ × 0.99)
     ≈ 0.764
```

This remains below 0.85.

Use 0.1% resistors if measurement repeatability justifies them, but safety does not depend on 0.1% tolerance.

# SUM-01 headroom

Maximum first-pass limited Return amplitude:

```text
approximately 5.6 Vpp at RETURN_LIMITED
```

After fixed 0.749 attenuation:

```text
5.6 Vpp × 0.749 ≈ 4.19 Vpp maximum returned component
```

This may coincide with shaped Present. SUM-01 and ADC conditioning must therefore:

- preserve headroom for Present plus limited Return;
- intentionally limit/scale the sum before PCM3168A ADC full scale;
- avoid using converter clipping as Break;
- keep nominal operation near the accepted −12 dBFS target.

The clamp protects against runaway amplitude; it does not replace correct ADC gain staging.

# Absence influence

RET-03 derives a slow control signal from `RETURN_LIMITED` only.

Required structure:

```text
RETURN_LIMITED
   ↓
precision rectifier
   ↓
attack/release smoothing
   ↓
fixed maximum scaling/clamp
   ↓
ABSENCE_INFLUENCE
```

`ABSENCE_INFLUENCE` must:

- be neutral during reset/fault;
- remain within ABS-01's accepted control range;
- have no audio-rate positive-feedback path;
- use a dedicated test point.

Exact attack/release values remain an emotional-response schematic decision, but the control maximum must be fixed in hardware.

# OPA1679 channel allocation

Prototype A requires seven OPA1679 quad packages.

```text
7 packages × 4 channels = 28 channels
```

The native schematic may move a channel between closely related functions, but it may not exceed 28 channels without reopening the power and package count.

No additional spare OPA1679 package is authorised.

## Current budget

OPA1679 current per channel:

```text
typical 2.0 mA
worst-case 2.8 mA across temperature
```

For 28 channels:

```text
typical = 56.0 mA per rail
worst   = 78.4 mA per rail
```

This count is included in the separate power budget.

## Unused-channel rule

The locked allocation uses every channel.

If native schematic capture leaves a channel unused:

- it must be wired in a datasheet-compliant stable state;
- the reason must be documented;
- another uncounted function may not silently consume it later.

# Bench acceptance

```text
[ ] SSI Return VCA cannot produce gain above unity.
[ ] No valid control voltage is negative.
[ ] Clamp is symmetric enough for the accepted behaviour.
[ ] Clamp remains active with MCU reset.
[ ] Clamp remains active with codec/control DAC faulted.
[ ] Only RETURN_LIMITED crosses the Return-sheet feedback boundary.
[ ] Fixed feed gain measures below 0.80 including tolerance.
[ ] Present + maximum limited Return does not cause uncontrolled ADC clipping.
[ ] Complete loop remains bounded at every valid setting.
[ ] 30-minute worst-setting Return/Break/Pressure endurance test passes.
```
