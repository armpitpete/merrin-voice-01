# V5.2 — MCU Pin Allocation Register

## Status

Open verification register.

No physical pin is accepted until checked against STM32H743VI LQFP-100 official data and a conflict-free CubeMX allocation.

## Required peripheral groups

| Group | Required signals | Status |
|---|---|---|
| Audio transport | MCLK, BCLK, LRCLK/FS, SDIN, SDOUT | Unassigned |
| Codec control | SPI or I2C, codec reset/mute | Unassigned |
| Control DAC | I2C SCL/SDA | Unassigned |
| Panel ADC | Time, Fade, Blur, Distance, Drift, Presence, Return, Present/wet | Unassigned |
| Safety | watchdog heartbeat, hardware-mute release, fault sense | Unassigned |
| State | IDLE/ACTIVE/WARNING/ERROR LED control | Unassigned |
| User inputs | reset/clear, bypass/safe mute, service/test | Unassigned |
| Debug | SWDIO, SWCLK, NRST, optional SWO | Reserved, exact pins pending |
| Clock source | HSE input/output or approved oscillator input | Unassigned |

## Allocation rules

- Prefer one SAI block for all PCM3168A TDM transport.
- Keep all audio clocks on supported high-speed alternate-function pins.
- Do not reuse SWD pins for normal controls.
- Keep boot-strap pins in deterministic states.
- Assign panel controls only to ADC-capable pins.
- Reserve at least one spare ADC-capable pin and two spare GPIOs.
- Avoid pins that create power-domain or package conflicts.
- Record the exact alternate-function number for every audio pin.
- Record DMA request/controller choices for audio receive and transmit.

## Required evidence artifact

Store one of the following before this register may close:

- checked-in CubeMX `.ioc` file generated for STM32H743VIT6; or
- a pin-allocation export plus a written cross-check against the current datasheet.

The evidence must show no peripheral conflicts and must preserve debug access.
