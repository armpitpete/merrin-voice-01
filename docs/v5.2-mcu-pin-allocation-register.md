# V5.2 — MCU Pin Allocation Register

## Status

Accepted for schematic capture.

This allocation is for:

```text
STM32H743VIT6
LQFP-100
```

It was cross-checked against the current STM32H743VI package pinout, alternate-function tables, and ST's STM32H743 SAI example. No physical pin is duplicated.

This acceptance does not authorise PCB placement or routing.

## Locked audio transport

Prototype A uses SAI1 with adjacent GPIOE pins.

| Signal | SAI function | MCU pin | Physical pin | AF | Direction |
|---|---|---:|---:|---:|---|
| `CODEC_MCLK` | SAI1_MCLK_A | PE2 | 1 | AF6 | MCU → codec |
| `CODEC_SDIN_TO_MCU` | SAI1_SD_B | PE3 | 2 | AF6 | codec → MCU |
| `CODEC_LRCLK` | SAI1_FS_A | PE4 | 3 | AF6 | MCU → codec |
| `CODEC_BCLK` | SAI1_SCK_A | PE5 | 4 | AF6 | MCU → codec |
| `CODEC_SDOUT_FROM_MCU` | SAI1_SD_A | PE6 | 5 | AF6 | MCU → codec |

### SAI block roles

```text
SAI1 Block A = master transmitter
SAI1 Block B = synchronous receiver
```

Block A generates MCLK, BCLK and frame sync. Block B receives the PCM3168A ADC stream while synchronised to Block A.

The transport contract is:

```text
48 kHz frame rate
8 slots per frame
32 bits per slot
24 significant audio bits
256 BCLK periods per frame
12.288 MHz BCLK
24.576 MHz MCLK
```

DMA request/controller allocation remains a firmware configuration item. It must use DMA-accessible buffers and must not place the 384,000-byte history buffer in a DMA-only work area.

## Locked control bus

PCM3168A and MCP4728 share I2C1.

| Signal | Peripheral | MCU pin | Physical pin | AF | Direction |
|---|---|---:|---:|---:|---|
| `CTRL_I2C_SCL` | I2C1_SCL | PB8 | 95 | AF4 | MCU → devices |
| `CTRL_I2C_SDA` | I2C1_SDA | PB9 | 96 | AF4 | bidirectional |

Locked 7-bit addresses:

```text
PCM3168A = 0x44
MCP4728  = 0x60
```

The addresses do not conflict.

PCM3168A address straps:

```text
ADR1 = 0
ADR0 = 0
```

The PCM3168A control-mode pin must be strapped to the datasheet-defined I2C state in the schematic.

## Locked panel analogue inputs

The eight primary digital controls use dedicated ADC-capable pins.

| Control | MCU pin | Physical pin | ADC input |
|---|---:|---:|---|
| Memory Time | PA0 | 22 | ADC1_INP16 / ADC12_INP0 |
| Memory Fade | PA1 | 23 | ADC1_INP17 / ADC12_INP1 |
| Memory Blur | PA2 | 24 | ADC12_INP14 |
| Ghost Distance | PA3 | 25 | ADC12_INP15 |
| Ghost Drift | PA4 | 28 | ADC12_INP18 |
| Ghost Presence | PA5 | 29 | ADC12_INP19 |
| Return amount | PA6 | 30 | ADC12_INP3 |
| Present/wet balance | PA7 | 31 | ADC12_INP7 |

The schematic must include appropriate source impedance, filtering and protection for each ADC input.

Reserved spare ADC-capable pins:

```text
PB0 — physical pin 34
PB1 — physical pin 35
```

Neither spare is allocated in Prototype A.

## Locked safety and operating GPIO

| Signal | MCU pin | Physical pin | Direction | Safe-state requirement |
|---|---:|---:|---|---|
| `CODEC_RESET_N` | PD8 | 55 | output | asserted until clocks and rails are valid |
| `CODEC_MUTE_N` | PD9 | 56 | output | muted during boot/reset/fault |
| `FAULT_SENSE_N` | PD10 | 57 | input | detects combined supervisor/watchdog fault |
| `WATCHDOG_HEARTBEAT` | PD11 | 58 | output | independent periodic heartbeat |
| `HARDWARE_MUTE_RELEASE` | PD12 | 59 | output | cannot defeat the external fault clamp |
| `SERVICE_TEST` | PD13 | 60 | input | service-only, defined default state |
| `RESET_CLEAR` | PD14 | 61 | input | debounced clear/reset request |
| `SAFE_MUTE` | PD15 | 62 | input | immediate safe-mute request |

`HARDWARE_MUTE_RELEASE` is permission only. The hardware clamp remains authoritative and must force attenuation when the MCU is reset, absent or faulted.

## Locked SLS-1 state outputs

|---|---:|---:|---|
| `STATE_LED_R` | PC6 | 63 | output/PWM-capable |

## Reserved clock, reset and debug pins

| Function | MCU pin | Physical pin | Rule |
|---|---:|---:|---|
| HSE input | PH0-OSC_IN | 12 | reserved for crystal/oscillator network |
| HSE output | PH1-OSC_OUT | 13 | reserved for crystal network if used |
| Hardware reset | NRST | 14 | supervisor, reset button and SWD access |
| SWDIO | PA13 | 72 | permanently reserved for SWD |
| SWCLK | PA14 | 76 | permanently reserved for SWD |

SWO remains optional and unassigned. SWD pins must not be repurposed in Prototype A.

```text

[PASS] Eight panel controls use unique PA0–PA7 ADC-capable pins.
[PASS] Safety and user controls use unique PD8–PD15 pins.
[PASS] SLS-1 outputs use unique PC6–PC9 pins.
[PASS] HSE, NRST, SWDIO and SWCLK remain reserved.
[PASS] Spare ADC and GPIO capacity remains.
[PASS] No selected signal uses the same physical pin twice.
```

## Schematic-capture rules

1. Use the exact STM32H743VIT6 LQFP-100 symbol and package.
2. Record physical pin numbers as well as port names.
3. Label SAI data directions from the MCU perspective.
4. Keep PB8/PB9 pull-ups in the 3.3 V domain.
5. Do not connect a 5 V control signal directly to any MCU pin.
6. Preserve SWD and NRST test access.
7. Give every unused MCU pin an explicit documented state.
8. Re-run the allocation against the native schematic before ERC acceptance.
