## Why this architecture

The design needs:

- one mono ADC ingress
- three independent DAC outputs: Memory, Ghost, and Return send
- one shared retained history
- enough RAM for meaningful Memory time without external memory
- real-time audio processing with safety margin
- practical SMD packages rather than the smallest available parts
- hardware-independent reset/mute supervision

The selected architecture meets those needs without adding external SDRAM, a second processor, or several unrelated effects chips.

## MCU — STM32H743VIT6

### Locked role

The STM32H743VIT6 is the Prototype A digital core.

It performs:

- audio DMA and SAI/TDM transport
- shared circular Memory buffer
- Memory degradation
- Ghost derivation
- Return-send generation
- digital control scanning
- state machine and SLS-1 state output
- reset/clear sequencing
- watchdog heartbeat

### Package target

```text
LQFP-100
```

This is chosen over smaller BGA/QFN variants because it is easier to inspect, rework, and prototype.

### Memory budget

Locked audio format inside the core:

```text
48 kHz
mono retained history
32-bit processing samples
2.0-second circular buffer
```

Buffer use:

```text
48,000 samples/s × 4 bytes × 2.0 s = 384,000 bytes
```

Allocation rule:

- circular history buffer in AXI SRAM
- DMA buffers in DMA-accessible SRAM selected during firmware/schematic integration
- control/state/watchdog data outside the main history buffer
- no external SDRAM or PSRAM on Prototype A

Ghost and Return use taps/derived processing from the same history. They do not receive separate full-length buffers.

### Processing target

- 64-sample audio blocks by default
- approximately 1.33 ms block duration at 48 kHz
- average audio processing should remain below 50% of available block time during worst accepted settings
- watchdog heartbeat must not depend on the audio callback completing incorrectly

The exact firmware architecture remains a later implementation lane, but the schematic must expose the required SAI, I2C, debug, reset, and control pins.

## Audio converter — PCM3168A

### Locked role

One PCM3168A provides all Prototype A conversion channels.

Functional channel use:

| Converter function | Prototype A use |
|---|---|
| ADC channel 1 | shaped Present + limited Return ingress |
| DAC channel 1 | Memory output |
| DAC channel 2 | Ghost output |
| DAC channel 3 | Return send |
| Remaining ADC/DAC channels | muted or placed in the datasheet-defined unused state |

### Locked format

```text
48 kHz sample rate
24-bit converter data
32-bit TDM slots
MCU as audio clock master
codec as clock slave
```

Preferred clock plan:

- LRCLK: 48 kHz
- BCLK: 12.288 MHz for eight 32-bit slots
- MCLK: 24.576 MHz preferred, subject to final PCM3168A clock-mode validation
- SAI/TDM transport between MCU and codec
- control bus by SPI or I2C as selected during schematic capture; SPI is preferred if it simplifies deterministic boot configuration

The exact serial-mode register configuration must be checked against the PCM3168A datasheet before schematic acceptance.

### Supply domains

- codec analogue supply: quiet 5 V
- codec digital supply/interface: 3.3 V
- codec reset held active until rails, clock, and MCU state are valid
- analogue outputs remain muted during boot/reset/fault

### Analogue-domain rule

Codec analogue pins use the codec’s required common-mode/bias conditions.

External and main analogue paths remain centred around 0 V on the ±12 V analogue rails.

Therefore the schematic must include explicit AC coupling, level translation, biasing, and reconstruction/anti-alias stages at the converter boundary.

No codec output may be connected directly to a ±12 V analogue stage without the required interface network.

## General analogue op amp — OPA1679

### Locked family role

OPA1679 is the default quad audio op-amp family for:

- input buffer and trim support
- Pressure stages
- Absence stages
- Memory-input summing
- converter anti-alias/reconstruction support where appropriate
- Break/Return shaping
- envelope/control extraction support
- wet/final mixing
- output drive support

### Supply target

```text
±12 V analogue rails
```

### Package target

```text
TSSOP-14
```

SOIC may be used only where schematic/layout evidence shows a practical reason.

The final op-amp count is determined by schematic channel accounting. Unused amplifiers must be terminated in a datasheet-compliant stable state.

## VCA — SSI2164

### Locked role

One SSI2164 provides four analogue gain-control channels.

Initial channel allocation:

| SSI2164 channel | Function |
|---|---|
| 1 | Memory analogue level |
| 2 | Ghost analogue level |
| 3 | Return amount/feed level |
| 4 | wet master / hardware wet attenuation |

### Package target

```text
SOP-16
```

### Safety rule

The SSI2164 control network must default to maximum safe attenuation when:

- power is rising
- MCU is held reset
- codec is invalid
- control DAC is absent or unconfigured
- supervisor/watchdog asserts fault

The MCP4728 is not the only mute mechanism.

A hardware clamp/bias network must force the datasheet-defined maximum-attenuation state independently of firmware.

Exact control-voltage scaling and polarity are schematic-stage calculations.

## Control DAC — MCP4728

### Locked role

The MCP4728 provides four normal-operation VCA control voltages.

| DAC channel | VCA target |
|---|---|
| A | Memory level |
| B | Ghost level |
| C | Return level |
| D | wet master |

### Package target

```text
MSOP-10
```

### Bus and supply

- I2C control from MCU
- 3.3 V supply preferred
- local decoupling and quiet reference handling
- update rate adequate for panel control and controlled ramps; not used as an audio-rate modulation source

### Power-up rule

Do not rely on arbitrary stored EEPROM values for safety.

The hardware attenuation clamp remains authoritative until SAFE-01 deliberately releases it.

Any EEPROM configuration used later must encode a safe attenuated start state and be documented.

## Reset and watchdog architecture

## TPS3808G33 supervisor

Role:

- monitor the 3.3 V digital rail
- provide manual reset input
- hold MCU/codec/safety logic in reset until the rail is valid
- provide a controlled reset delay

Package target:

```text
SOT-23-6
```

## TPS3431 independent watchdog

Role:

- monitor an MCU heartbeat independent of the audio process
- assert fault if firmware stops servicing the watchdog
- force wet/Return attenuation and system reset

Package target:

```text
VSON-8
```

This is the least hand-friendly selected IC package.

Construction consequence:

- use stencil/reflow or assembly service for this device
- expose probe access to watchdog input/output nets
- do not place it beneath panel hardware

## Hardware fault combination

Supervisor and watchdog fault outputs must combine into a hardware-safe signal that can:

1. hold/reset the MCU
2. reset/mute the PCM3168A
3. force the SSI2164 hardware attenuation clamp
4. assert ERROR state indication

Open-drain fault combination is preferred where compatible with the selected devices.

Exact transistor/logic implementation remains schematic work.

## Power architecture

Prototype A uses protected ±12 V input rails.

This is a prototype electrical choice, not a final enclosure-format decision.

### Analogue rails

```text
+12 V analogue
0 V
−12 V analogue
```

Used by:

- OPA1679 analogue stages
- SSI2164
- Pressure/Absence/Break/Return circuitry
- final mix/output stages

### 5 V path

```text
+12 V
  ↓
TPS62160 adjustable buck to approximately 5.5 V
  ↓
TPS7A2050 low-noise LDO
  ↓
quiet 5 V codec-analogue rail
```

The pre-regulator target provides LDO headroom while reducing dissipation.

Exact switching frequency, inductor, compensation, filter, and passive values remain schematic calculations.

### 3.3 V path

```text
+12 V
  ↓
TPS62160 adjustable buck
  ↓
3.3 V digital rail
```

Used by:

- STM32H743
- codec digital/interface supply
- MCP4728
- supervisor/watchdog logic
- digital state/control circuitry

The codec digital branch may use ferrite/local filtering if validated in the schematic.

### Power-entry requirements

- reverse-polarity protection
- rail filtering
- local bulk and high-frequency decoupling
- current-limited bench bring-up points
- separate labelled rail test points
- no use of the −12 V rail for digital conversion

Exact power connector and protection parts remain schematic-stage choices.

## Audio clock architecture

The STM32 is the clock master.

Clock tree:

```text
MCU audio PLL
  ├── MCLK to PCM3168A
  ├── BCLK to PCM3168A
  └── LRCLK to PCM3168A
```

Rules:

- no free-running independent codec oscillator in Prototype A
- clock starts before codec reset is released
- codec mute remains active until clock and register state are valid
- exact HSE crystal/oscillator part remains to be selected during schematic capture
- dedicated low-jitter audio oscillator is added only if measured validation shows the MCU-derived clock is inadequate

## Panel/control acquisition

### Direct analogue controls

These remain in their analogue blocks where practical:

- input trim
- Pressure
- Absence
- Break
- final output level

### MCU-scanned controls

The MCU internal ADC scans:

- Memory Time
- Memory Fade
- Memory Blur
- Ghost Distance
- Ghost Drift
- Ghost Presence
- Return amount
- Present/wet balance

No external analogue multiplexer is required for Prototype A unless schematic pin accounting proves otherwise.

### Digital inputs

- Reset / clear Memory
- bypass / safe mute
- optional service/test input

### State outputs

- SLS-1 state LED control
- hardware mute release
- codec reset/mute
- watchdog heartbeat

## Exact jack selection

The selected current Thonkiconn variant is:

```text
WQP518MA
```

Use two:

- J1 AUDIO IN
- J2 AUDIO OUT

Rules:

- exact switched-contact behaviour verified against the manufacturer drawing
- footprint dimensions checked independently before PCB routing
- no-cable AUDIO IN state tied to a defined quiet reference through the intended switched contact or input network
- panel-hole, nut/washer, and adjacent-control clearances checked before layout
- jack sleeves follow the single documented analogue-ground strategy

## Passive/package rules

### Default

```text
0805 resistors and ceramic capacitors
```

### Allowed denser use

```text
0603 only around dense MCU/codec/regulator areas where 0805 is impractical
```

### Not allowed by default

- 0402 passives
- BGA packages
- wafer-level packages
- unnecessarily small QFN packages where a leaded option exists

### Exceptions

- manufacturer-required regulator passives may use 0603
- VSON-8 watchdog is an accepted reflow-only exception
- thermal/current requirements may justify larger packages

Every exception must be visible in the schematic/BOM review.

## Firmware resource boundary

Prototype A firmware must remain inside this hardware budget:

- internal MCU SRAM only
- two-second mono retained history
- no file system
- no sample loading
- no presets
- no USB audio
- no MIDI
- no display
- no external storage
- no external SDRAM/PSRAM

The firmware must preserve one shared history and derive Memory, Ghost, and Return from it.

## Schematic verification gates

Before V5.2 can be marked complete, schematic work must verify:

```text
[ ] STM32 pin count covers SAI/TDM, I2C/SPI, ADC controls, debug, reset, LEDs, and buttons.
[ ] PCM3168A clock mode supports the chosen MCLK/BCLK/LRCLK relationship.
[ ] Unused codec channels are in documented safe states.
[ ] AXI SRAM buffer allocation leaves adequate margin.
[ ] ADC/DAC bias and AC-coupling networks are explicit.
[ ] OPA1679 channel count is complete.
[ ] SSI2164 control polarity and attenuation range are calculated.
[ ] Hardware clamp forces wet/Return attenuation without firmware.
[ ] MCP4728 power-up cannot create audible wet/Return output.
[ ] Supervisor/watchdog faults reach MCU, codec mute/reset, and VCA clamp.
[ ] TPS62160 regulator values and magnetics are calculated from official design equations.
[ ] TPS7A2050 has adequate dropout and dissipation margin.
[ ] WQP518MA symbol, switched contact, and footprint are verified.
[ ] Every supply pin has local decoupling.
[ ] Every rail and major signal block has required test access.
[ ] ERC passes with only documented intentional exceptions.
```
