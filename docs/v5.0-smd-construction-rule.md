# V5.0 — SMD Construction Rule

## Status

Locked hardware requirement.

## Core rule

Merrin Grief Synth circuit boards must use surface-mount electronic components by default.

```text
Electronic circuitry = SMD-first.
Panel and mechanical hardware = through-hole only where appropriate.
```

This rule applies to:

- Memory Core Prototype A
- later analogue Present-path boards
- Memory / Ghost / Return processing boards
- Absence / Pressure / Break circuitry
- control-scanning and state-light circuitry
- later internal voice-source boards
- production-intent revisions unless a documented exception is approved

## Why

SMD construction is the intended build method because it supports:

- compact circuit boards
- shorter signal paths
- repeatable assembly
- easier transition to assembled PCB production
- reduced dependence on large through-hole footprints
- realistic integration of digital audio, memory, conversion, and control circuitry

## Allowed through-hole exceptions

Through-hole parts are allowed where they are mechanically or practically superior.

Typical exceptions include:

- panel potentiometers
- audio and CV jacks
- switches
- encoders
- power connectors
- board-to-panel connectors
- programming or service headers
- test points
- components requiring mechanical anchoring
- parts unavailable in a practical SMD package
- unusually high-power or high-heat parts where the circuit design justifies it

An exception must be based on engineering or repairability, not habit.

## Package-size principle

V5.0 does not select exact footprints yet.

When footprint selection begins, prefer SMD packages that remain realistic to prototype, inspect, and repair.

The design should not use unnecessarily tiny packages merely to reduce board size.

The later schematic/PCB lane must explicitly choose a buildability target, such as:

- hand-assembly friendly
- hot-plate/reflow friendly
- assembly-service friendly

Exact choices such as 0805, 0603, SOIC, TSSOP, QFN, or other packages remain deferred until circuit and component selection.

## PCB rule

When PCB work begins:

- SMD components should be placed on one side where practical for easier prototype assembly
- panel hardware may occupy the opposite side if the mechanical design requires it
- test points must remain accessible
- programming/debug access must not be buried under panel hardware
- high-stress connectors must have adequate mechanical support
- serviceability must not be sacrificed solely for density

## Prototype A requirement

Memory Core Prototype A must be designed as an SMD-first board.

Prototype A may use temporary through-hole development headers, panel controls, and jacks, but the actual signal-processing and control circuitry must target SMD implementation.

A breadboard or large through-hole proof may be used only for a narrow bench experiment. It must not become the default hardware architecture or final board design.

## Relationship to V5.0

This rule does not select components or begin PCB layout.

It constrains all later choices:

```text
V5.0 architecture
↓
V5.1 circuit-block design
↓
schematic/component selection using SMD-first rule
↓
KiCad PCB design
```

## Acceptance rule

A later schematic or PCB is non-compliant unless:

- electronic circuitry is SMD-first
- through-hole exceptions are documented
- mechanical parts remain physically robust
- the board remains prototypeable and repairable
