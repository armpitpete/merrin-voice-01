## Return limiter

Corrected contract:

```text
combined small-signal gain from core Return source
through DAC-R, Break and analogue Return to RETURN_LIMITED
≤ 1.000
```

Hard boundary:

```text
RET-01
→ 2.2 kΩ
→ clamp to buffered ±2.5 V references
→ RETURN_LIMITED
→ fixed feed:
   RIN = 40.2 kΩ
   RF = 27.4 kΩ
   nominal = 0.6816
   1% worst-case ≈ 0.6954
```

Therefore calculated normal loop gain remains below 0.70 and below the accepted 0.85 ceiling.

Conservative headroom check:

```text
5.6 Vpp clamp × 0.6816 = 3.82 Vpp Return
3.82 Vpp Return + 2.00 Vpp Present = 5.82 Vpp
```

This stays below the 6 Vpp internal headroom target.
