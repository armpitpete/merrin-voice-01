## Return limiter

Locked calculation:

```text
raw Return DAC
→ Break
→ nonlinear Return
→ 2.2 kΩ series resistor
→ Schottky clamp to buffered ±2.5 V references
→ RETURN_LIMITED
→ 30.1 kΩ / 40.2 kΩ fixed feed
→ nominal gain magnitude 0.7488
→ 1% worst-case approximately 0.764
```

SSI Return control cannot exceed unity.

The calculated normal small-signal loop ceiling therefore remains below 0.85.

Detailed evidence:

- `docs/v5.2-return-limiter-and-opamp-allocation.md`

Still required:

- native schematic path review;

- measured loop gain;
- 30-minute worst-setting endurance test.


Critical interpretation:

