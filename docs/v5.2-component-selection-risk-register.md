## R12 — Return limiter

Calculation closed for schematic preparation; schematic and bench proof open.

Corrected requirements:

```text
combined small-signal transfer from core Return source
through DAC-R, Break and analogue Return to RETURN_LIMITED
≤ 1.000
```

Hard boundary:

```text
RET-01
→ 2.2 kΩ
→ dual-polarity clamp to buffered ±2.5 V references
→ RETURN_LIMITED
→ fixed feed:
   RIN = 40.2 kΩ
   RF = 27.4 kΩ
   nominal = 0.6816
   1% worst-case ≈ 0.6954
```

SSI Return control cannot exceed unity, so calculated loop gain remains below 0.70 and below the accepted 0.85 ceiling.

Headroom check:

```text
5.6 Vpp clamp × 0.6816 = 3.82 Vpp Return
3.82 Vpp + 2.00 Vpp Present = 5.82 Vpp
```

This remains below the 6 Vpp internal target.

Open:

- native small-signal gain table;
- measured clamp/loop gain;
- 30-minute worst-setting endurance.

Evidence:

- `docs/v5.2-return-limiter-and-opamp-allocation.md`
