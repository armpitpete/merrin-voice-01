## R5 — TPS3431 timing, package and assembly

**Status:** Partially closed.

Accepted timing role:

```text
TPS3431 = slower independent MCU-hang/reset watchdog
selected timeout ≈ 200 ms nominal
published range ≈ 170–230 ms
```

Critical interpretation:

```text
20 ms requirement = asserted fault to suppression
not MCU-hang detection latency
```

After supervisor, watchdog, manual or firmware fault assertion, the hardware clamp/mute path must begin wet/Return suppression within 20 ms.

Open before PCB acceptance:

- current TI VSON-8 land pattern verified;
- exposed pad and stencil process accepted;
- WDI/WDO test access present;
- assembly method stated and tested.

Evidence:

- `docs/v5.2-ssi2164-mcp4728-fail-safe-control.md`
- `docs/v5.2-supervisor-watchdog-and-thonkiconn-proof.md`

## R12 — Return limiter independence

**Status:** Calculation closed for schematic preparation; physical proof open.

Locked safety chain:

```text
DAC-R
→ Break
→ analogue Return
→ 2.2 kΩ series limiter
→ dual-polarity Schottky clamp to buffered ±2.5 V references
→ RETURN_LIMITED buffer
→ fixed 0.749 Return-feed gain
→ SUM-01
```

Fixed feed values:

```text
RIN = 40.2 kΩ
RF  = 30.1 kΩ
nominal gain magnitude = 0.7488
1% worst-case ratio ≈ 0.764
```

SSI2164 Return control cannot exceed unity. The calculated small-signal loop ceiling therefore remains below 0.85.

Only `RETURN_LIMITED` may export feedback audio from the Return sheet.

Evidence:

- `docs/v5.2-return-limiter-and-opamp-allocation.md`

Open before hardware acceptance:

- native schematic cross-check;
- measured clamp levels;
- measured loop gain;
- 30-minute worst-setting endurance test.
