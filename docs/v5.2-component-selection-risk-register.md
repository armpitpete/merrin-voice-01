## R1 — PCM3168A clock and configuration

**Status:** Closed for schematic preparation.

Locked:

```text
48 kHz LRCLK
12.288 MHz BCLK
24.576 MHz MCLK
8 × 32-bit TDM slots
24 significant bits
SAI1 Block A master transmitter
SAI1 Block B synchronous receiver
PCM3168A I2C address 0x44
```

Channel map:

```text
DAC1 Memory
DAC2 Ghost
DAC3 Return send
ADC1 shaped Present + RETURN_LIMITED
```

The exact startup register sequence, mute values and unused-channel states are recorded in:

- `docs/v5.2-pcm3168a-clock-and-interface-proof.md`
- `docs/v5.2-mcu-pin-and-codec-cross-check.md`

Remaining implementation proof:

- generated STM32 SAI configuration must match the accepted frame contract;
- critical PCM3168A registers must be read back during bring-up;
- hardware must fault-muted on clock, DMA or readback failure.

## R2 — STM32H743 SRAM and DMA placement

**Status:** Open.

The two-second 32-bit mono history uses 384,000 bytes of AXI SRAM.

Required closure:

- produce a memory-region table;
- reserve the circular history explicitly;
- place DMA buffers in DMA-accessible SRAM;
- prove stack, heap, control state and audio work buffers fit;
- retain at least 64 KB uncommitted safety margin after the first complete firmware link.

Owner lane: firmware architecture after schematic pin/clock acceptance.

## R3 — SSI2164 attenuation polarity and range

**Status:** Open.

An incorrect gain-law interpretation could make reset increase gain instead of attenuation.

Required closure:

- calculate the datasheet transfer function;
- state control voltages for unity and maximum safe attenuation;
- define MCP4728 scaling;
- define a hardware clamp that overrides MCU/DAC output;
- verify safe state with MCU absent, DAC absent and watchdog asserted.

Owner lane: V5.2 analogue/safety calculation.

## R4 — MCP4728 startup and EEPROM state

**Status:** Open.

Stored/default DAC outputs must not request audible wet or Return gain during startup.

Required closure:

- hardware clamp remains active until explicit safe release;
- EEPROM values are unused or deliberately programmed safe;
- startup is safe with MCU held reset;
- I2C failure leaves all wet/Return paths attenuated.

The shared I2C address is closed:

```text
MCP4728 = 0x60
PCM3168A = 0x44
```

Owner lane: V5.2 schematic and bring-up firmware.

## R11 — Unused PCM3168A channels

**Status:** Digital configuration closed; analogue treatment open.

Locked digital treatment:

- DAC4 receives zero and remains muted;
- DAC5–8 remain muted and power-save is enabled;
- ADC2 remains muted;
- ADC3–6 remain muted and power-save is enabled;
- inactive slots never enter the Memory engine or wet mixer.

Still required in the native schematic:

- apply datasheet-compliant analogue termination to ADC2 and other unused analogue inputs;
- show that no unused DAC output reaches a mixer;
- verify the final PCM3168A symbol pins and channel labels.

Owner lane: codec-sheet schematic capture.

## R12 — Return limiter independence

**Status:** Open.

Required closure:

- RET-02 is an analogue hardware limiter;
- `RETURN_LIMITED` is the only feedback-audio net exported from the Return sheet;
- the limiter remains active with MCU, codec or control DAC faulted;
- complete loop-gain calculation and worst-setting bench test.

Owner lane: V5.2 schematic and independent safety review.
