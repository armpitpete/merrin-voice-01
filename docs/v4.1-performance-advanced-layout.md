# V4.1 — Performance / Advanced Layout Separation

## Purpose

V4.1 separates the visible instrument surface from the advanced/test surface.

This is a layout and clarity lane only.

It supports the real goal:

```text
Build Merrin Grief Synth — Constrained Grief as a circuit-board synth.
```

The browser synth is the proof-of-voice and control reference. It is not the final destination.

V4.1 makes that browser reference cleaner before hardware translation begins.

## Boundary

Allowed:

- keep the performance controls visible
- move test/diagnostic controls into an advanced/test section
- keep panic/release visible for safety
- keep MIDI connection/status visible
- keep MIDI diagnostics and raw monitor available but advanced
- preserve current sound behaviour
- make the browser reference clearer for later hardware translation

Forbidden:

- sound-design changes
- new synthesis controls
- demo media
- PCB layout
- schematic design
- part selection
- BOM
- KiCad files
- DBHT-1 work
- M A C work
- VST work
- VCV Rack work
- sequencer work
- hardware expansion
- preset system
- recording/export

## Implementation summary

V4.1 changes the page structure so the public instrument reference is seen first:

```text
Performance layer
  - Play voice sample
  - Panic / release notes
  - MIDI connect
  - status text
  - playable controls
  - keyboard
  - emotion controls
  - oscilloscope

Advanced / test layer
  - All effects off
  - Normal voice
  - effect test switches
  - Wither delay
  - MIDI diagnostics
  - raw MIDI monitor
```

## Why this matters for hardware

A circuit-board synth needs a clean decision surface before schematic work starts.

The hardware translation should not be based on a page that mixes:

- player controls
- diagnostic switches
- MIDI debugging
- effect-isolation tools
- temporary browser-development aids

V4.1 separates those things so the later hardware spec can ask a clearer question:

```text
Which controls belong on the real panel?
Which behaviours belong in firmware/circuitry?
Which tools are only for development and testing?
```
