# V4.1 — Performance / Advanced Layout Separation

## Purpose

V4.1 separates the visible instrument surface from the advanced/test surface.

This is a layout and clarity lane only.

## Boundary

Allowed:

- keep the performance controls visible
- move test/diagnostic controls into an advanced/test section
- keep panic/release visible for safety
- keep MIDI connection/status visible
- keep MIDI diagnostics and raw monitor available but advanced
- preserve current sound behaviour

Forbidden:

- sound-design changes
- new synthesis controls
- demo media
- DBHT-1 work
- M A C work
- VST work
- VCV Rack work
- sequencer work
- hardware expansion
- preset system
- recording/export

## Implementation summary

V4.1 changes the page structure so the public instrument is seen first:

```text
Performance layer
  - Play voice sample
  - Panic / release notes
  - MIDI connect
  - status text
  - playable controls
  - keyboard
  - emotion controls
  - oscilloscope

Advanced / test layer
  - All effects off
  - Normal voice
  - effect test switches
  - Wither delay
  - MIDI diagnostics
  - raw MIDI monitor
```

## Files changed

- `index.html`
- `layout-fix-v37.css`

## Notes

The audio engine is not changed.

MIDI behaviour is not changed.

A small layout mount keeps dynamically created MIDI diagnostics and raw MIDI monitor panels inside the advanced/test area.
