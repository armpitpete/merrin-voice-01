# TPS3808 supervisor

## Selected role

TPS3808G33 monitors the 3.3 V rail and provides:

- active-low open-drain reset/fault output;
- manual-reset input;
- controlled reset delay;
- hardware-safe startup independent of MCU firmware.

## Locked timing target

Use the datasheet's resistor-programmed fixed-delay mode:

```text
CT resistor to VDD = 50 kΩ starting value
reset delay target ≈ 300 ms nominal
```

The accepted purpose is not audio timing. The long delay keeps:

- MCU reset asserted;
- PCM3168A reset/mute asserted;
- TMUX1574 safe selector on +3.3 V attenuation;
- wet/Return paths suppressed;

while the digital rail and clocks stabilise.

The native schematic must include resistor tolerance and the TPS3808 timing range before final acceptance.

## Manual reset

Manual reset must:

1. assert the hardware fault/mute path immediately;
2. force `SAFE_CONTROL_RELEASE` low;
3. force Return control to maximum attenuation;
4. reset the MCU and codec state as defined;
5. keep wet/Return suppressed for the full reset delay.

Manual reset may not depend solely on software polling.

# TPS3431 independent watchdog

## Selected role

TPS3431 remains the independent MCU-hang detector.

Locked timing target:

```text
CWD = 10 kΩ to VDD
SET1 = high
watchdog timeout ≈ 200 ms nominal
published window approximately 170–230 ms
reset pulse approximately 170–230 ms
```

`WDO` is active-low open-drain and joins the hardware fault network.

Required test access:

```text
TP-WDI
TP-WDO
```

## Timing boundary

TPS3431 does not meet a 20 ms MCU-hang-detection requirement.

The accepted safety interpretation is:

```text
fault assertion → wet/Return suppression begins within 20 ms
```

TPS3431 may take approximately 170–230 ms to decide that the MCU has stopped. Once it asserts `WDO`, the analogue clamp/mute path must begin suppression within 20 ms.

Immediate faults and explicit MCU ERROR states assert the clamp without waiting for TPS3431.

If the project later requires detection of a frozen MCU itself within 20 ms, TPS3431 must be replaced or augmented. That is not hidden by this acceptance.

## Hardware fault combination

Supervisor and watchdog outputs are combined in the safe direction.

Required logic:

```text
any asserted fault
   ↓
SAFE_CONTROL_RELEASE forced low
codec mute/reset asserted as appropriate
wet/output hardware suppression asserted
MCU reset asserted where required
SLS-1 ERROR state requested where power remains valid
```

Open-drain wired-AND/OR semantics must be shown unambiguously in the native schematic.

A firmware-controlled release signal may release the safe state only when no hardware fault holds it active.

# TPS3431 package and assembly

Selected package:

```text
VSON-8 with exposed pad
```

This remains the least hand-friendly selected active package.

Locked assembly rules:

- use the current TI land pattern, not an inferred generic VSON footprint;
- include the exposed pad exactly as required;
- use stencil/reflow or an assembly service;
- provide visible or probe-accessible `WDI`, `WDO`, supply and ground test points;
- do not place the device beneath panel hardware;
- include a post-assembly watchdog functional test.

R5 is not fully closed for PCB work until the exact footprint is independently checked in the native library and the assembly process is accepted.

# WQP518MA Thonkiconn proof

## Selected part

```text
WQP518MA
3.5 mm vertical PCB-mount mono switched jack
```

It is the current Thonkiconn-family selection for:

- J1 AUDIO IN;
- J2 AUDIO OUT.

## Electrical pin roles

The current manufacturer drawing establishes:

| Pin | Function |
|---:|---|
| 1 | sleeve |
| 2 | tip |
| 3 | normally-connected tip switch |

Switching behaviour:

```text
no plug inserted: pins 2 and 3 connected
plug inserted: pins 2 and 3 open
```

The symbol must represent the normally-closed relationship explicitly.

## AUDIO IN no-cable state

J1 uses the switched contact to create a defined quiet no-cable state.

Locked intent:

- tip remains the external audio signal;
- switched tip contact connects the input network to its quiet reference when no plug is inserted;
- inserting a plug opens the quiet-reference normal and gives control to the external source;
- the input may not float with no cable.

The exact resistor/reference connection is a native input-sheet decision and must preserve input protection and source impedance.

## AUDIO OUT switching

J2 does not need to use its switched tip contact for Prototype A performance behaviour.

The unused switch contact must be explicitly marked no-connect or assigned a documented service role. It may not float into the output network accidentally.

## Mechanical and footprint evidence

The current WQP518MA manufacturer drawing is the footprint authority.

Locked mechanical rules:

- use the exact current drawing dimensions and hole centres;
- include the recommended approximately 3 mm PCB hole/keepout beneath the jack barrel where required by the drawing;
- verify panel axis, threaded bushing, nut/washer stack and insertion clearance;
- verify neighbouring control clearance before layout;
- verify sleeve grounding follows the single documented analogue-ground strategy.

The part is described as footprint-compatible/interchangeable with the current related Thonkiconn/PJ398SM/PJ301M-12 family, but that compatibility does not replace independent footprint checking.

## Community KiCad library status

A community KiCad library linked from the product information is available, but its own README warns that the library is incomplete and should not be used as authoritative fabrication data.

Therefore:

```text
community footprint = reference only
manufacturer drawing = authority
independent footprint check = mandatory
```

No downloaded community footprint is accepted blindly.
