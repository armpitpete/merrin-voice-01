# V5.2 — MCU Pin and Codec Configuration Cross-Check

## Status

Accepted evidence record for schematic preparation.

## Purpose

Cross-check the locked STM32H743VIT6 pin allocation and PCM3168A configuration as one system before native schematic capture.

## Evidence used

### STMicroelectronics

- current STM32H743VI datasheet and LQFP-100 pinout;
- STM32H743VI alternate-function tables;
- official STM32CubeH7 `STM32H743I-EVAL/Examples/SAI/SAI_AudioPlay` example showing:
  - PE2 = SAI1_MCLK_A, AF6;
  - PE4 = SAI1_FS_A, AF6;
  - PE5 = SAI1_SCK_A, AF6;
  - PE6 = SAI1_SD_A, AF6;
- datasheet assignment PE3 = SAI1_SD_B;
- datasheet ADC assignments for PA0–PA7;
- datasheet package positions for HSE, NRST, SWD and all selected GPIO.

### Texas Instruments

- current PCM3168A datasheet;
- 512 × fs system-clock support at 48 kHz;
- eight-slot, 32-bit-slot TDM framing;
- I2C address selection by ADR1/ADR0;
- DAC and ADC serial-format registers;
- pairwise converter power-save controls;
- per-channel soft mute controls.

### Microchip

- current MCP4728 datasheet;
- default device code/address selection giving 7-bit address `0x60`.

## Cross-check table

| Question | Result | Evidence conclusion |
|---|---|---|
| Do all five audio signals fit one SAI instance? | PASS | SAI1 A/B uses PE2–PE6 without duplication. |
| Is the audio AF consistent? | PASS | ST official H743 example uses AF6 for SAI1 PE2/4/5/6; PE3 is the matching SAI1_SD_B pin. |
| Are transmit and receive directions unambiguous? | PASS | PE6 carries MCU TX to PCM3168A DIN1; PE3 carries PCM3168A DOUT1 to MCU RX. |
| Is the TDM clock relationship valid? | PASS | 24.576 MHz = 512 × 48 kHz; BCLK is 8 × 32 × 48 kHz = 12.288 MHz. |
| Are the codec and control-DAC I2C addresses distinct? | PASS | PCM3168A `0x44`; MCP4728 `0x60`. |
| Do the used DAC channels match the slot map? | PASS | slots 0–2 map to DAC1–3: Memory, Ghost, Return send. |
| Does the used ADC channel match the slot map? | PASS | slot 0 maps to ADC1: shaped Present + `RETURN_LIMITED`. |
| Are unused converters explicitly controlled? | PASS | inactive DACs are muted/powered down; inactive ADCs are muted/powered down or terminated. |
| Can codec startup create wet output before validation? | PASS, conditional | codec starts muted and external SSI2164 clamp remains asserted until validation. |
| Are debug and clock pins preserved? | PASS | PH0/PH1, NRST, PA13 and PA14 are reserved. |
| Are eight ADC controls available without conflict? | PASS | PA0–PA7 are uniquely allocated to ADC-capable inputs. |
| Is spare capacity retained? | PASS | PB0/PB1 ADC spares and PB12–PB15 GPIO spares remain. |

## Locked interface summary

```text
STM32H743VIT6 LQFP-100

PE2  SAI1_MCLK_A  → PCM3168A SCKI
PE3  SAI1_SD_B    ← PCM3168A DOUT1
PE4  SAI1_FS_A    → PCM3168A LRCK
PE5  SAI1_SCK_A   → PCM3168A BCK
PE6  SAI1_SD_A    → PCM3168A DIN1

PB8  I2C1_SCL
PB9  I2C1_SDA

PCM3168A 7-bit address: 0x44
MCP4728  7-bit address: 0x60
```

## Locked normal channel state

```text
DAC1  Memory       active and unmuted
DAC2  Ghost        active and unmuted
DAC3  Return send  active and unmuted
DAC4               digital zero and muted
DAC5–8             muted / power-save

ADC1  shaped Present + RETURN_LIMITED  active and unmuted
ADC2               muted and safely terminated
ADC3–6             muted / power-save
```

## Safety cross-check

The codec mute register is not the primary safety device.

Safe startup requires all three layers:

1. PCM3168A reset/mute;
2. zeroed SAI transmit/DMA buffers;
3. independent hardware attenuation clamp around wet and Return paths.

A single firmware or control-bus fault must not create audible Return gain.

## Remaining boundaries

This evidence closes:

```text
R1  PCM3168A clock/configuration architecture
R10 STM32H743VIT6 pin allocation
```

It does not close:

- SRAM/DMA linker placement;
- SSI2164 gain-law and clamp calculations;
- power/current/thermal budgets;
- watchdog timing and footprint review;
- WQP518MA symbol/footprint proof;
- OPA1679 channel/current count;
- analogue Return limiter calculation;
- native schematic ERC.

PCB placement, routing, fabrication and purchasing remain forbidden.
