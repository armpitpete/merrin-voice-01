# V5.2 — PCM3168A Clock and Interface Proof

## Status

Architecture clock accepted. Register-level configuration pending.

## Selected operating point

```text
Sample rate: 48 kHz
Converter word length: 24 bits
Transport slot width: 32 bits
Transport: TDM
MCU: clock master
PCM3168A: clock slave
```

## Channel need

Prototype A requires:

```text
ADC 1: shaped Present + RETURN_LIMITED
DAC 1: Memory
DAC 2: Ghost
DAC 3: Return send
```

PCM3168A provides six ADC and eight DAC channels, so the required channel count fits with unused channels held in documented safe states.

## System-clock proof

Preferred MCLK:

```text
24.576 MHz
```

Calculation:

```text
24,576,000 / 48,000 = 512
```

PCM3168A documents 512 × fs as an allowed system-clock ratio for both ADC and DAC sections in the selected sample-rate range.

Result:

```text
24.576 MHz at 48 kHz = architecture-level PASS
```

## BCLK target

The current architecture target is:

```text
8 slots × 32 bits × 48,000 frames/s = 12.288 MHz
```

This is a transport target, not yet a register-level acceptance.

## Items still requiring exact proof

- whether one common eight-slot TDM frame can carry the required ADC and DAC streams exactly as planned;
- PCM3168A serial-mode register values;
- ADC and DAC data alignment;
- BCLK polarity and sampling edge;
- frame-sync width/polarity;
- slot ordering;
- unused channel mute/power state;
- STM32 SAI frame configuration;
- codec reset and mute release order;
- control-interface choice: SPI or I2C.

## Preferred control interface

SPI remains preferred for deterministic boot configuration unless pin allocation shows a clear reason to use I2C.

This is not locked until the MCU pin register is complete.

## Safe startup sequence

1. Hardware attenuation clamp asserted.
2. PCM3168A reset and mute asserted.
3. 3.3 V and quiet 5 V rails validated.
4. MCU clock tree becomes stable.
5. MCLK/BCLK/LRCLK become valid.
6. PCM3168A leaves reset but remains muted.
7. Serial and control registers are written and read back where supported.
8. Unused channels enter documented safe states.
9. DSP/DMA state becomes valid.
10. Wet paths ramp from silence.
11. Hardware clamp releases only after the complete safety state is valid.

## Failure rule

Any clock, configuration, DMA or watchdog failure must:

- assert codec mute/reset as appropriate;
- force wet and Return VCAs to maximum safe attenuation;
- preserve the independent analogue Present path where electrically safe;
- show ERROR state.

## Acceptance gate

This document closes only when the exact PCM3168A register map and STM32 SAI configuration are recorded and independently reviewed.
