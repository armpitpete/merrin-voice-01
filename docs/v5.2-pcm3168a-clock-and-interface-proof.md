# V5.2 — PCM3168A Clock and Interface Proof

## Status

Accepted for schematic capture and firmware configuration.

This document locks the Prototype A PCM3168A transport, control interface, channel allocation, startup writes and failure behaviour.

It does not authorise PCB placement or routing.

## Locked operating point

```text
Sample rate:          48 kHz
Converter word:       24 bits
Transport slot:       32 bits
Slots per frame:      8
Transport:            I2S-compatible TDM
MCU role:             clock master
PCM3168A role:        clock slave
MCLK:                 24.576 MHz
BCLK:                 12.288 MHz
LRCLK/frame rate:     48 kHz
```

Proof:

```text
24,576,000 / 48,000 = 512 × fs
8 × 32 × 48,000      = 12,288,000 BCLK/s
```

PCM3168A supports the required 512 × fs system clock and eight-channel TDM framing at the selected single-rate operating point.

## Locked physical transport

| PCM3168A role | MCU signal | MCU pin |
|---|---|---|
| system clock input | `CODEC_MCLK` | PE2 / SAI1_MCLK_A |
| ADC serial output to MCU | `CODEC_SDIN_TO_MCU` | PE3 / SAI1_SD_B |
| frame sync | `CODEC_LRCLK` | PE4 / SAI1_FS_A |
| serial bit clock | `CODEC_BCLK` | PE5 / SAI1_SCK_A |
| DAC serial input from MCU | `CODEC_SDOUT_FROM_MCU` | PE6 / SAI1_SD_A |

```text
SAI1 Block A = master transmitter
SAI1 Block B = synchronous receiver
```

The final STM32 SAI implementation must reproduce the TI TDM frame shown for 24-bit I2S TDM: eight 32-bit slots and 256 BCLK periods per frame.

## Locked control interface

The PCM3168A uses I2C software control on the shared I2C1 bus.

```text
7-bit PCM3168A address = 0x44
ADR1 = 0
ADR0 = 0
```

The MCP4728 remains at its default 7-bit address:

```text
MCP4728 address = 0x60
```

There is no address conflict.

The PCM3168A mode-selection pin must be strapped to the datasheet-defined I2C control state. PB8/PB9 pull-ups remain in the 3.3 V domain.

## Locked PCM3168A configuration values

Register numbers are shown in hexadecimal.

### Safe initial state

| Register | Value | Meaning |
|---:|---:|---|
| `0x40` | `0xC0` | reset/control defaults retained; automatic DAC sampling mode |
| `0x44` | `0xFF` | mute all eight DAC channels |
| `0x55` | `0x3F` | mute all six ADC channels |

### DAC configuration

| Register | Value | Meaning |
|---:|---:|---|
| `0x41` | `0x06` | DAC slave mode; 24-bit I2S TDM format |
| `0x42` | `0xC0` | DAC1–4 operating; DAC5–8 power-save; normal filter choice |
| `0x43` | `0x00` | normal DAC phase |
| `0x46` | `0x00` | independent attenuation; de-emphasis disabled |
| `0x47`–`0x4F` | `0xFF` | master/channel attenuation at documented 0 dB default |

DAC4 remains digitally zero and muted during normal Prototype A operation even though its converter pair remains active with DAC3.

### ADC configuration

| Register | Value | Meaning |
|---:|---:|---|
| `0x50` | `0x00` | automatic ADC sampling mode |
| `0x51` | `0x06` | ADC slave mode; 24-bit I2S TDM format |
| `0x52` | `0x60` | ADC1/2 operating; ADC3–6 power-save; high-pass filter enabled |
| `0x53` | `0x00` | differential ADC input mode |
| `0x54` | `0x00` | normal ADC phase |
| `0x57` | `0x00` | independent attenuation/default overflow behaviour |
| `0x58`–`0x5E` | `0xFF` | master/channel attenuation at documented 0 dB default |

ADC2 remains muted and must receive the datasheet-compliant unused-input treatment in the analogue schematic.

## Locked startup write sequence

The external SSI2164 attenuation clamp is asserted before this sequence begins.

1. Hold PCM3168A hardware reset active.
2. Establish and validate 3.3 V digital and quiet 5 V analogue rails.
3. Start stable MCLK, BCLK and LRCLK from SAI1 Block A.
4. Release PCM3168A hardware reset while keeping codec and external wet paths muted.
5. Probe I2C address `0x44`.
6. Write `0x40 = 0xC0`.
7. Write `0x44 = 0xFF` and `0x55 = 0x3F`.
8. Write DAC configuration registers `0x41`, `0x42`, `0x43`, `0x46`, and `0x47`–`0x4F`.
9. Write ADC configuration registers `0x50`–`0x55` and `0x57`–`0x5E` as listed above.
10. Read back the critical registers where supported:

```text
0x40  0x41  0x42  0x44
0x50  0x51  0x52  0x55
```

11. Start SAI DMA with all transmit slots initialised to digital zero.
12. Confirm valid frame, DMA and watchdog state.
13. Change DAC mute register from `0xFF` to `0xF8`:

```text
DAC1 Memory       unmuted
DAC2 Ghost        unmuted
DAC3 Return send  unmuted
DAC4–8            muted
```

14. Change ADC mute register from `0x3F` to `0x3E`:

```text
ADC1 unmuted
ADC2–6 muted
```

15. Ramp wet control values from silence.
16. Release the external hardware attenuation clamp only after every safety condition is valid.

## Locked normal mute values

```text
DAC mute register 0x44 = 0xF8
ADC mute register 0x55 = 0x3E
```

A reset, configuration error or watchdog fault returns the system to:

```text
DAC mute register 0x44 = 0xFF
ADC mute register 0x55 = 0x3F
external hardware attenuation clamp asserted
```

## STM32 SAI configuration contract

The native SAI/CubeMX implementation must satisfy all of these conditions:

```text
SAI1 Block A: master transmitter
SAI1 Block B: synchronous receiver
sample rate: 48 kHz
protocol: I2S-compatible TDM matching PCM3168A Figure 52
frame length: 256 bits
active slots: 8
slot size: 32 bits
data size: 24 bits
Block A transmit slots: 0–7
Block B receive slots: 0–7
MCLK output: 24.576 MHz
BCLK output: 12.288 MHz
```

The exact STM32 register bit pattern may be generated by CubeMX/HAL, but the generated configuration must be checked against this contract and the PCM3168A frame diagram. Generated code is evidence, not authority: any mismatch must be corrected before codec mute is released.

## Unused-channel treatment

- DAC4 transmit data is always zero and the channel remains muted.
- DAC5–8 remain muted and their converter pairs are placed in power-save mode.
- ADC2 remains muted and receives the documented unused analogue-input termination.
- ADC3–6 remain muted and powered down.
- No unused DAC output reaches the analogue wet mixer.
- No unused ADC slot enters the Memory buffer.

## Failure rule

Any of the following is a fault:

- I2C address failure;
- critical register readback mismatch;
- missing or invalid MCLK/BCLK/LRCLK;
- SAI frame error;
- DMA underrun/overrun;
- watchdog fault;
- codec rail fault;
- unexpected non-zero inactive TDM slot.

A fault must:

1. assert the external wet/Return attenuation clamp;
2. mute/reset the PCM3168A as appropriate;
3. force Return control to zero;
4. preserve the direct analogue Present path only where electrically safe;
5. display SLS-1 ERROR state.
